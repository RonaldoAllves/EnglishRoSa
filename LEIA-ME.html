⚠️ IMPORTANTE: Como Usar Este App

Este app precisa rodar em um servidor HTTP local. Não funciona abrindo o arquivo index.html diretamente!

🚀 Escolha uma Opção:

1️⃣Opção 1: Usando Python (MAIS FÁCIL)

Passo 1: Dê um duplo clique no arquivo:

START_SERVER.bat

ou

START_SERVER.ps1

Passo 2: Acesse no navegador:

http://localhost:8000
🚀 Abrir App (localhost:8000)

2️⃣Opção 2: Comando Manual

Passo 1: Abra o PowerShell nesta pasta

Passo 2: Execute:

python -m http.server 8000

Passo 3: Acesse: http://localhost:8000

3️⃣Opção 3: VS Code (Para Desenvolvedores)

  1. Instale a extensão "Live Server" no VS Code
  2. Abra a pasta D:\English\APP no VS Code
  3. Clique com botão direito em index.html
  4. Escolha "Open with Live Server"

4️⃣Opção 4: Node.js

Se você tem Node.js instalado:

npx http-server

✅ Por que preciso disso?

Por segurança, navegadores modernos bloqueiam o carregamento de arquivos JSON quando você abre um HTML diretamente (protocolo file://).

Um servidor HTTP local resolve esse problema e é totalmente seguro - roda apenas no seu computador!
