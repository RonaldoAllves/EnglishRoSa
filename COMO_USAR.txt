⚠️  ATENÇÃO IMPORTANTE:

Este app precisa rodar em um SERVIDOR HTTP LOCAL.
NÃO funciona abrindo o index.html diretamente!


╔═══════════════════════════════════════════════════════════════╗
║  🚀 OPÇÃO 1: MAIS FÁCIL (RECOMENDADO)                        ║
╚═══════════════════════════════════════════════════════════════╝

1. Dê DUPLO CLIQUE em um destes arquivos:
   
   📄 START_SERVER.bat
   OU
   📄 START_SERVER.ps1

2. Uma janela preta vai abrir (não feche!)

3. Abra seu navegador e acesse:
   
   🌐 http://localhost:8000

4. Pronto! O app vai abrir! 🎉


╔═══════════════════════════════════════════════════════════════╗
║  🔧 OPÇÃO 2: COMANDO MANUAL                                   ║
╚═══════════════════════════════════════════════════════════════╝

1. Pressione Shift + Botão Direito nesta pasta
2. Escolha "Abrir janela do PowerShell aqui"
3. Digite:
   
   python -m http.server 8000

4. Acesse: http://localhost:8000


╔═══════════════════════════════════════════════════════════════╗
║  💻 OPÇÃO 3: VS CODE                                          ║
╚═══════════════════════════════════════════════════════════════╝

1. Abra esta pasta no VS Code
2. Instale a extensão "Live Server"
3. Clique direito em index.html
4. Escolha "Open with Live Server"


╔═══════════════════════════════════════════════════════════════╗
║  ❓ POR QUE PRECISO DISSO?                                    ║
╚═══════════════════════════════════════════════════════════════╝

Por segurança, navegadores bloqueiam o carregamento de arquivos
JSON quando você abre um HTML diretamente (protocolo file://).

Um servidor HTTP local resolve isso e é totalmente seguro - 
roda apenas no seu computador!

╔═══════════════════════════════════════════════════════════════╗
║  🆘 PROBLEMAS?                                                ║
╚═══════════════════════════════════════════════════════════════╝

❌ Python não encontrado?
   → Instale em: https://www.python.org/downloads/
   → Marque "Add Python to PATH" na instalação

❌ Porta 8000 já em uso?
   → Use outra porta: python -m http.server 8080
   → Acesse: http://localhost:8080

❌ Ainda não funciona?
   → Abra LEIA-ME.html para mais opções
   → Ou use a extensão Live Server do VS Code
